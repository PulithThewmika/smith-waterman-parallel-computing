# `report/graphs/` — Performance figures

All graphs are generated by [`scripts/plot.py`](../../scripts/README.md) from
[`data/results.csv`](../../data/README.md). Speedup is `T_serial / T_parallel`, measured
against the averaged serial baseline (0.249 s on the reference hardware). Problem size
8000×8000, seed 12345.

Regenerate with:

```bash
./scripts/run_benchmarks.sh 8000 8000 12345
python3 scripts/plot.py
```

## MPI — column-block pipeline

| ![MPI execution time vs processes](mpi_time.png) | ![MPI speedup vs processes](mpi_speedup.png) |

Best **5.20×** at 16 processes — the overall winner on the reference hardware; near-linear to

## CUDA — anti-diagonal kernels

| Kernel time vs block size | Speedup vs block size |
| --- | --- |
| ![CUDA kernel time vs block size](cuda_time.png) | ![CUDA speedup vs block size](cuda_speedup.png) |
