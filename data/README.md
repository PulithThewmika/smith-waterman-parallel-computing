# `data/` — Benchmark output

Holds the measurement output produced by the benchmark and consumed by the plotting script.

## `results.csv`

Generated by [`scripts/run_benchmarks.sh`](../scripts/README.md) and read by
[`scripts/plot.py`](../scripts/README.md). One row per individual run (the script does `REPS`
runs per configuration; `plot.py` averages them).

### Schema

```
impl,config,m,n,score,time
```

| Column | Meaning |
| --- | --- |
| `impl` | `serial`, `openmp`, `mpi`, or `cuda` |
| `config` | thread count (OpenMP), process count (MPI), block size (CUDA), or `1` (serial) |
| `m`, `n` | sequence lengths |
| `score` | maximum alignment score — **must be identical across all rows** for the same `m`/`n`/seed |
| `time` | matrix-fill time in seconds (kernel-only for CUDA) |

### Example

```csv
impl,config,m,n,score,time
serial,1,8000,8000,3545,0.247809
openmp,8,8000,8000,3545,0.088600
mpi,16,8000,8000,3545,0.047900
cuda,32,8000,8000,3545,0.104300
```

## Regenerating

```bash
./scripts/run_benchmarks.sh 8000 8000 12345   # rewrites data/results.csv
```

> `results.csv` is a generated artifact and is listed in `.gitignore`.
